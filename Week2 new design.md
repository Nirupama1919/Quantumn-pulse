Week 2 – Enterprise Financial Dashboard

Project Overview

During Week 2, I worked on improving the Enterprise Financial Dashboard by focusing on Progressive Disclosure, Component Architecture, and Auto Layout. The goal was to create a more organized, consistent, and user-friendly financial interface using Figma.

Column 1 – HCI Research & Architecture

Progressive Disclosure

I studied Progressive Disclosure, a UX principle that presents essential information first and reveals additional details when users need them. This approach helps users understand complex financial data without overwhelming the dashboard.

Key work completed:

- Identified essential financial information that should be visible by default.
- Organized secondary information to be accessed when required.
- Planned how transaction details could be revealed without overcrowding the main dashboard.
- Focused on reducing visual clutter and improving information accessibility.
- Considered how progressive disclosure could improve the usability of financial dashboards.

Column 2 – UI Design & Motion Prototyping

Component Architecture & Auto Layout

I worked on the Enterprise Financial Dashboard design in Figma, focusing on reusable components, layout consistency, and organized financial data presentation.

Key work completed:

- Designed KPI cards for Total Revenue, Total Expenses, and Net Profit.
- Created a Recent Transactions section with transaction IDs, descriptions, amounts, and statuses.
- Designed a Monthly Revenue Overview chart.
- Added Dashboard Filters for Date Range, Category, and Status.
- Created reusable components for KPI cards, transaction rows, and filter elements.
- Practiced applying Auto Layout to maintain consistent spacing and alignment.
- Improved the structure and organization of dashboard elements.

Design Improvements

- Organized financial information into clear sections.
- Improved visual hierarchy between headings, labels, and financial values.
- Maintained consistent spacing and alignment.
- Used reusable components to reduce repeated design work.
- Focused on readability and a professional dashboard appearance.

Learning Outcomes

- Understood the practical use of Progressive Disclosure in dashboard UX.
- Learned how component architecture supports reusable UI design.
- Practiced using Auto Layout in Figma.
- Improved understanding of financial dashboard organization.
- Gained experience in creating structured and consistent UI elements.

Conclusion

Week 2 helped me understand how research-based UX principles and reusable UI components can improve a financial dashboard. By applying Progressive Disclosure concepts and practicing Component Architecture with Auto Layout in Figma, I developed a better understanding of designing structured, scalable, and user-friendly interfaces.
